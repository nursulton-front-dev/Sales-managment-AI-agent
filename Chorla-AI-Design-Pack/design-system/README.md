# Система оформления
Это параметры для интеграции в существующий CSS, не готовая замена globals.css.
Сначала проверь действующий theme provider и используй один способ переключения темы.

– Заголовок страницы: 24–28px, 600. Основной текст: 14–16px, 400–500.
– Подписи: 12–14px. Не уменьшать важный текст ради совпадения с PNG.
– Отступы: 4, 8, 12, 16, 24, 32px. Между разделами: 24–32px.
– Карточки 8px, элементы управления 6px. Минимальная тень, тонкая рамка.
– Одна главная кнопка на блок. Не копировать повторяющиеся CTA с макета.
– На мобильном область нажатия от 44px, шрифт полей от 16px.
– Иконки Lucide 18–20px в навигации, 16px в кнопках, stroke 1.75.
– SVG с currentColor наследует цвет при inline-вставке. У img цвет внешнего SVG не наследуется: для него используй mask или готовые компоненты lucide-react.
– Брендовые иконки сохраняют свои цвета. Не применять к ним общий CSS filter.
– Анимации 120–180ms; выключать необязательное движение при prefers-reduced-motion.
– Сайдбар закреплён; при недостаточной высоте прокручивается центральное меню. На телефоне drawer с управлением фокусом.
– Статус нельзя обозначать только цветом. Focus-visible, подписи полей и контраст проверяются на реализации.

Рекомендуемый шрифт: уже подключённый в проекте, если он читаемый и содержит кириллицу. Не заменять без необходимости.
Тёмная тема представлена токенами; отдельные тёмные макеты в этом архиве отсутствуют.
