# Анимированный воробей

Откройте index.html в браузере для просмотра. Кнопки позволяют остановить движение и повторить анимации.

- sparrow-loading.svg — циклическое ожидание; показывать только во время реальной загрузки.
- sparrow-hello.svg — два взмаха при приветствии, затем моргание.
- sparrow-success.svg — один прыжок, затем моргание; показывать после подтверждённого результата.
- sparrow-idle.svg — статичная версия.

Это самостоятельно отрисованные векторные формы с прозрачным фоном и встроенной CSS-анимацией. Графика упрощена относительно растрового концепта. Можно подключить через img, без библиотек анимации. Все анимированные SVG учитывают prefers-reduced-motion. При длительном размещении предоставьте остановку движения или используйте статичную версию. Для декоративного применения используйте пустой alt, а статус сообщайте отдельным текстом.

Веб-платформа не изменялась, публикация не выполнялась. Локально проверены отображение страницы, кнопка остановки и отсутствие горизонтального переполнения при ширине 375 px.
