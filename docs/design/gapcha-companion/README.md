# Персонаж gapcha AI

`source/concept.png` — оригинальный сгенерированный эскиз; он не вырезан из скриншота. Рабочие SVG в `public/illustrations/gapcha/companion/` нарисованы отдельно по этому направлению: `hello` — приветствие; `loading` — ожидание; `empty` — пустое состояние; `success` — подтверждённый успех; `error` — ошибка и 404; `support` — помощник. Каждый SVG является самостоятельным редактируемым векторным исходником и одновременно компактным файлом для сайта. Векторные формы сохранены в одном стиле без встроенных растровых изображений.

Декоративные изображения имеют пустой alt. Статус всегда сообщается текстом. Движение задаётся CSS и отключается при prefers-reduced-motion; статичные SVG работают без JavaScript. `animate={false}` отключает движение в конкретном месте.

## Направление по референсу

`source/elder-character-sheet.png` — новый оригинальный эскиз аксакала, созданный по предоставленному референсу: белая борода, тёмная тюбетейка, бирюзовый чапан и оранжевый пояс. В интерфейсе применены отдельно нарисованные упрощённые векторы `public/illustrations/gapcha/elder/{hello,loading,empty,success,error,support}.svg`; они не являются фрагментами скриншота или увеличением эскиза. Предыдущие файлы сохранены в `companion/`.

## Анимации и применение

Статичные исходники: `public/illustrations/gapcha/elder/`. Отдельные оптимизированные анимированные SVG: `public/illustrations/gapcha/elder-animated/`. В приветствии движется выделенная рука и один раз моргают глаза; поддержка повторяет жест один раз; ожидание мягко движется только во время загрузки; успех кратко подпрыгивает; ошибка мягко наклоняется. Анимация внутри SVG не требует JavaScript и отключена при `prefers-reduced-motion: reduce`; `animate={false}` выбирает отдельный статичный файл. Миниатюрный аватар статичен.

Приветствие: быстрый старт и мастер, лендинг; ожидание: загрузка данных и мастер; пустой список: лиды и диалоги; успех: сохранение настройки сотрудника; ошибка: ошибки загрузки и 404; поддержка: ассистент платформы. Тексты и действия расположены рядом и не зависят от изображения.

Текущие файлы интерфейса — `elder-v3/` (статичные) и `elder-v3-animated/` (с теми же позами и анимацией); в них уточнены белая борода, усы и брови. Версии `elder/` и `elder-animated/` сохранены для сравнения.
